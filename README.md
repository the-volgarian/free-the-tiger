# Free the Tiger

A mini-game built with TypeScript, PixiJS 7 and GSAP.

## Install and run

```bash
npm install
npm run dev
```

## Check and build

```bash
npm run typecheck
npm run build
npm run preview
```

## How to play

Open the browser console to see the code. Click the numbered buttons in that order to free the tiger. A wrong choice resets the attempt and generates a new code.

Music starts automatically when allowed by the browser, otherwise on the first click.
